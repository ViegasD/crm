# Fontes locais privadas

Esta pasta guarda os dois ZIPs originais de WhatsApp e `Proposta.pdf`, movidos sem alterar conteudo. Os arquivos binarios sao ignorados pelo Git; este indice e versionado.

O PDF antecede a inversao de prioridade e nao e a proposta atualizada de entregas. Os ZIPs contem material privado; audios e videos nao foram integralmente analisados. Leia o [handoff](../context/HANDOFF_COMPLETO.md) e o [escopo atual](../../SCOPE.md) antes de usar essas fontes.

Os nomes originais foram preservados. O manifesto em `docs/reports/WORKSPACE_RELOCATION_2026-11-11.json` registra caminhos e SHA-256 conferidos durante a movimentacao.
